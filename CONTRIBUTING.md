# Contributing

Read `AGENTS.md`, `README.md`, `WORKFLOW.md`, and `TASKS.md`. Use the sibling
`opensagetv-vibe-build-env` project and run `dev.cmd all` on Windows or
`./dev.sh all` on Linux/WSL. Do not hand-edit generated Android resources;
change the SVG, INI, generator, or asset contract and regenerate them.

Preserve the bundled font's OFL license and update `CHANGELOG.md`, `HANDOFF.md`,
and `TASKS.md` with behavior or workflow changes.
